Core del proyecto

El sistema entero desde un único sitio, de lo resumido a lo detallado. Cada documento dice cuándo se generó o se revisó por última vez — y si el código cambió después. Un documento sin fecha es un documento en el que no se puede confiar, y aquí se ve.
