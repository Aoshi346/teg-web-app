## WHAT WORKS: KEY INSIGHTS

### 1. Loss Aversion > Gain Framing
Versions using loss language ("estás perdiendo", "mientras lees esto") consistently outperformed those focusing on gains. The v47/v50 comparison table showing "Sin IA" vs "Con IA" is the single strongest conversion element.

**Best implementation:** v50, v47, v25, v22

### 2. Miller Credibility Is Irreplaceable
The Miller card (bio, stats, quote, avatar) adds ~1 point to any version's conversion score. Personal brand = trust = conversion. The "Founder's promise" with 90-day guarantee is the ultimate trust signal.

**Best implementation:** v50, v48, v41, v31

### 3. ROI Calculator = Commitment Device
Calculator versions (v22, v31, v41, v49, v50) generate higher engagement because users input their own data, creating psychological investment. The number "€180k/mes" is more compelling than abstract claims.

**Best implementation:** v50, v41, v31, v22

### 4. Live Social Proof = FOMO Engine
The live ticker showing "Carlos M. +€23.000" creates urgency and social validation. Combined with countdown timer and scarcity ("3 plazas"), it triggers action.

**Best implementation:** v50, v46, v38

### 5. Full-Screen Chat Demo = Highest Engagement
Versions with chat overlay (v38, v41, v49, v50) keep users on page 3-5x longer. The chatbot becomes the product demo, reducing the need for a human sales call.

**Best implementation:** v38 (clean), v50 (comprehensive), v49 (robust)

### 6. €23k/30days Metric = Best Social Proof Number
This specific number (inmobiliaria case study) consistently outperforms generic claims. It's specific, believable, and emotionally resonant. Used in v40, v38, v41, v49, v50.

### 7. 90-Day Guarantee = Risk Reversal
The guarantee removes the final objection. "Skin in the game" framing (Miller's own words) is more credible than generic money-back guarantees.

### 8. 7-Day Implementation = Barrier Removal
Knowing it takes only 7 days removes the "this will take months" objection. Speed-to-value is a key differentiator from competitors.
